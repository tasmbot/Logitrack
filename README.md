# Logitrack

## Модули системы
1. bot - Телеграм Бот для курьеров. С его помощью курьер берет заказ и система начинает отслеживать его геопозицию. Координаты курьера передается в соответствующий топик Kafka.
2. web_app - Веб-Приложение для курьеров, клиентов и операторов.
3. app - Приложение для клиентов и операторов (deprecated).
